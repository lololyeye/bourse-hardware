# Bourse du Hardware

Suivi des prix des composants PC façon bourse : watchlist, signaux d'achat, plan d'achat selon le budget, alertes et calendrier des promos.

Site statique (HTML/CSS/JS), aucune dépendance. Les données restent dans le navigateur (`localStorage`). On les partage avec le lien de partage ou un export `.json`.

## Lancer en local

```
python -m http.server 5173
```

Puis ouvrir http://localhost:5173.
